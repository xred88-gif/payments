# payments

Open https://xred88-gif.github.io/payments/ to run the app. Choose Create demo account on the login screen.

This browser-only demonstration composes message examples. It does not send payments or connect to SWIFT. Login and data storage are local to your browser; use test data.

The runnable build is index.html. Complete React source, build instructions, and an optional Actions deployment workflow are in payments-source.zip. The built-in administrator credential was removed before publishing.
