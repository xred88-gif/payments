# payments

Open https://xred88-gif.github.io/payments/ to run the app. Sign in with your configured single administrator account.

This browser-only demonstration composes message examples. It does not send payments or connect to SWIFT. Login and data storage are local to your browser; use test data.

The runnable build is index.html. Complete React source, build instructions, and an optional Actions deployment workflow are in payments-source.zip. Registration is disabled; one administrator account is configured.
